# GUTS_48
GUTS challenge 2026 - team 48

Dijkstra's Algorithm - Shortest path to nearest shower. Instructions about how the algorithm works on the page. Each step the user gets to choose what direction they want to go. If they pick correctly, they collect a fraction of a bar of soap. If they are wrong, they don't collect any soap but still go the correct way anyway. The user wins the game by collecting enough bits of soap to have a proper shower, and they lose if they do not have enough soap.
