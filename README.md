# GUTS_48
"Do you have the guts?" challenge 2026 entry for Morgan Stanley
GUTS challenge 2026 - team 48

An interactive walk-through demonstration game for Dijkstra's algorithm

Implemented using Java and Java Swing

<b> INSTRUCTIONS <br/></b>
<b>initial set up</b>
1. mkdir -p out
2. javac -d out $(find src -name "*.java")

<b>to run game (random seed/fixed seed)<br/></b>
java -cp out Main #random seed <br/>
java -cp out Main 12345 #fixed seed (for live demo to always get a "good" graph) <br/>
